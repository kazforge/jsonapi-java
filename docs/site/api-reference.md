# API Reference

Rendered Javadoc for the published **0.2.0** release is hosted by [javadocs.dev](https://www.javadocs.dev/).
Choose the reference matching your dependency version; these links do not follow `main` or `latest`.

| Artifact | Reference |
|----------|-----------|
| `jsonapi-java-api` | [Neutral application contracts](https://www.javadocs.dev/com.kazforge/jsonapi-java-api/0.2.0/index.html) |
| `jsonapi-java-jackson3` | [Jackson 3 runtime](https://www.javadocs.dev/com.kazforge/jsonapi-java-jackson3/0.2.0/index.html) |
| `jsonapi-java-jackson2` | [Jackson 2 runtime](https://www.javadocs.dev/com.kazforge/jsonapi-java-jackson2/0.2.0/index.html) |
| `jsonapi-java-core` | [Document model and validation](https://www.javadocs.dev/com.kazforge/jsonapi-java-core/0.2.0/index.html) |
| `jsonapi-java-annotations` | [Mapping annotations](https://www.javadocs.dev/com.kazforge/jsonapi-java-annotations/0.2.0/index.html) |
| `jsonapi-java-query` | [Query parsing](https://www.javadocs.dev/com.kazforge/jsonapi-java-query/0.2.0/index.html) |

Public mapping contracts ship in `jsonapi-java-api` under `com.kazforge.jsonapi.mapping`. The
`jsonapi-java-mapping` artifact and packages containing `internal` are unsupported implementation
details, not consumer APIs. If the external host is unavailable, the
[`JsonApi` source Javadoc at `v0.2.0`](https://github.com/kazforge/jsonapi-java/blob/v0.2.0/jsonapi-java-api/src/main/java/com/kazforge/jsonapi/api/JsonApi.java)
and the published Javadoc JARs on Maven Central remain available.
